# tournament-games

Stan na 30.10.2026: historyczne repozytorium przygotowania koncepcji gier turniejowych; brak aplikacji i bieżącego zadania wdrożeniowego.

Pierwotny kierunek: osobny anglojęzyczny serwis prostych gier opartych na zabawie i rywalizacji, niezależny od Play. Szczegóły produktu i finansowania nie zostały zatwierdzone.

Na prośbę użytkownika o uproszczenie współpracy usunięto stare instrukcje AGENTS, dokumenty procesu i skrypty kontrolujące wyłącznie te dokumenty. Wcześniejsze materiały pozostają w historii Git. Repozytorium zachowuje dotychczasową publiczną widoczność.

Dawne zadania i procedury nie są aktywnym zleceniem. Dalsza praca wymaga konkretnego bieżącego zadania; nie należy automatycznie odtwarzać dawnego workflow.
